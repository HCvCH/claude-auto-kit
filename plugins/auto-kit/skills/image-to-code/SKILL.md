# Image to Code

Visual builds lose fidelity between the reference and the code. This skill keeps every section tied to a concrete image.

## 1. Get one reference per section

- **User-provided:** screenshots, mockups, Figma exports — use them as they are.
- **Generated:** if an image generator is available (e.g. ComfyUI via Comfy MCP), generate one image per section (hero, features, pricing, footer …) in the picked style direction, same palette and type described in every prompt.
- **None available:** sketch the section as a quick wireframe description first and get an OK.

Save references to `./design/refs/<section>.png`.

## 2. Analyze before coding

For each reference, write down in a short table:

| Aspect | What to extract |
|---|---|
| Layout | grid, columns, alignment, max width, section height |
| Spacing | outer padding, gaps between groups, inner padding of components (estimate in px, snap to a 4/8 px scale) |
| Type | font style (serif/sans/display), sizes per level, weight, line height, letter spacing |
| Color | background, text, accent, borders — as hex, checked for contrast |
| Components | buttons (shape, radius, size, states), cards, inputs, icons |
| Imagery | photo vs illustration, crop, radius, shadow |
| Motion hints | what likely animates (only if the direction allows motion) |

Map every value to the project's DESIGN.md tokens; add tokens if something is missing instead of hard-coding.

## 3. Build section by section

1. Implement one section.
2. Screenshot it at the reference's width (`playwright-cli`).
3. Put screenshot and reference side by side and list every visible difference.
4. Fix until the differences are only intentional (real content, accessibility fixes).
5. Next section.

## Rules

- Never copy a real company's site 1:1 for a client project; use references for structure and quality, not brand identity.
- Text in generated references is placeholder — write real copy (and run `humanizer`).
- Images in the final page must be licensed: generated by the user, free stock, or provided by the client.
